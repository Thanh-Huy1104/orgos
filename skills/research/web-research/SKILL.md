# Web Research

## Process
1. Formulate search queries — be specific, use multiple angles
2. Search with web_search — aim for 3-5 diverse sources
3. Fetch relevant pages with web_fetch — read the full content
4. Verify claims — cross-reference between sources
5. Cite every claim with source URL

## Quality Standards
- Minimum 3 sources per research task
- Prefer authoritative sources (.gov, .edu, official docs)
- Flag conflicting information explicitly
- Note publication dates — prefer recent sources
- Distinguish fact from opinion
